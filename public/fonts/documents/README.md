# Document fonts

Noto Sans Regular and Bold, unmodified TTF files from the Noto project:

- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- License: SIL Open Font License 1.1, included in LICENSE.

Loaded from this application only when generating a PDF. The renderer subsets the embedded font and rejects unsupported characters rather than silently removing them.
